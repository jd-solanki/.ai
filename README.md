# JD Solanki's AI Setup

This AI Setup is distributed via [airig](https://github.com/jd-solanki/airig).

#### 1. Install `airig` globally

```shell
npm install --global @airig/cli
```

#### 2. Run add command inside your project

```shell
airig add jd-solanki/.ai@v1.0.22
```

### Getting Update

You can subscribe to releases of this repository to get notified of updates.

Here is how to set it up:

1. Look at the top-right corner on repo [page](https://github.com/jd-solanki/.ai) and click the Watch button.
2. Click Custom from the dropdown menu.Check the box for Releases and click Apply.
3. Now, you will get a notification every time we publish a new release with details about changes and improvements.
